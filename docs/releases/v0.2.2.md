# Atlas Exchange v0.2.2 — Capped Beta Signup

## Highlights

- Transactional admission limit of 20 total demo identities, including pending, suspended, and
  operator-provisioned accounts. Concurrent signup and provisioning share the same capacity check.
- Safe beta-full feedback in the registration interface and independent API/gateway signup and
  password-recovery configuration.
- Explicit authenticated TLS email configuration required before hosted account flows can open.
- Routed light/grey brokerage interface covering Dashboard, Trade, Orders, Portfolio, Funds,
  Profile, and role-protected Administration.
- Updated README with local setup and a two-account simulated buy/sell walkthrough.

## Deployment notes

- No database migration: expected schema version remains 15.
- Public signup and password recovery remain disabled by default in demo. Publishing this release
  does not enable either feature or update Render/Cloudflare.
- Before opening the beta, configure and verify real email delivery and complete the remaining
  bot/abuse-protection checks in `docs/engineering/capped-beta.md`.
- Use the published API image digest, not a mutable tag, for a separately authorized Render update.
- The standard workflow also publishes matching web and metrics-collector images.

Atlas remains a simulation: no real custody, deposits, withdrawals, or external order execution.
Reference market prices do not fill Atlas orders.
